# Magic Tower Roguelike

Pythonを学びながら、AIと段階的に制作する日本語テキスト型ローグライクRPGです。

## コンセプト

- 魔法の塔を探索し、敵を倒してレベルアップする
- レベルアップ時に3つのスキルから1つを選び、武器を進化させる
- 冒険者が死亡したら、新しい冒険者を作成する
- 過去の冒険者が発見した地図は次の冒険者へ継承される
- 発見済み地形は固定し、未探索領域だけをランダム生成する
- ボスを倒して脱出経路を開き、塔から脱出すれば勝利

## 別の端末で作業する

GitとCodexを利用できる端末で、このリポジトリをクローンする。

```bash
git clone https://github.com/aktkshqn/magic-tower-roguelike.git
cd magic-tower-roguelike
```

Codexでクローン先のフォルダをプロジェクトとして開く。同じGitHubリポジトリを共有元にすることで、コードと文書を複数端末で同期できる。

作業開始時:

```bash
git pull
```

作業終了時:

```bash
git add .
git commit -m "変更内容の要約"
git push
```

同じファイルを複数端末で同時に編集せず、端末を切り替える前にコミットとプッシュを行う。
