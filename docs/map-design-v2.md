# 地図表示・継承仕様 v2

## 目的

現在地、進める方向、未探索領域、重要地点を一目で判断できる地図を表示する。死亡した冒険者が発見した地形は、新しい冒険者へ知識として継承する。

## 表示例

```text
魔法の塔 1階                    冒険者: アレン  Lv.3
通常敵: 2 / 3体撃破

      01 02 03 04 05 06 07 08
   ┌────────────────────────┐
01 │ ■  ■  ■  ■  ■  ■  ■  ■  │
02 │ ■  ◉  ·  ·  ■  ?? ?? ■  │
03 │ ■  ■  ■  ·  ■  ?? ?? ■  │
04 │ ■  ·  ·  @  +  ?? ?? ■  │
05 │ ■  ·  ·  ·  ■  ?? ♛  ■  │
06 │ ■  ■  ■  ■  ■  ■  ⇧  ■  │
   └────────────────────────┘

現在地: 04列・04行
目標: ボスを倒して脱出経路を開く

凡例:
@  現在地    ◉  開始地点    ·  通路・部屋
■  壁        +  扉          ?? 未探索
⚔  戦闘中    ♛  ボス        ⇧  脱出経路
```

1マスを2文字幅で表示し、列と行に番号を付ける。`EN`、`BO`、`EX`のような略語は使わず、視覚的な記号で意味を判別できるようにする。

通常敵はランダムエンカウントのため、地図上には常設しない。戦闘が始まった瞬間だけ現在地を `⚔` で表示し、戦闘終了後は `@` に戻す。

## 地図の状態

各マスは地形と発見状態を別々に持つ。

- 地形：壁、床、扉、開始地点、ボス部屋、脱出経路
- 発見状態：未探索、視認済み、訪問済み
- 一時要素：現在地、戦闘中

現在地や戦闘記号は地形を上書きせず、表示時に重ねる。戦闘終了後も、床や部屋の情報は残る。

## 通常敵のランダムエンカウント

- 通常敵は地図上に配置・表示しない
- 各階の通常敵は3体を基準とする
- 1回のエンカウントでは1体の通常敵と戦う
- 前回の戦闘または階層開始から3～5歩移動した時点で、次の戦闘を発生させる
- 必要歩数は戦闘ごとに3、4、5のいずれかをランダムに選ぶ
- 開始地点、ボス部屋、脱出経路では通常エンカウントを発生させない
- 通常敵を3体倒した後は、その階で通常エンカウントを発生させない
- 逃走した戦闘は撃破数に含めず、次のエンカウント歩数を再抽選する
- ボスはランダムエンカウントではなく、地図上の `♛` へ入ると戦闘になる
- ボス撃破後、地図上の `⇧` が利用可能になる

3～5歩ごとの方式にすることで、完全な確率方式にある「長時間まったく敵が出ない」「短時間に連戦が続く」という偏りを抑える。

## 新しい冒険者への継承

```text
前回までに発見済み            新しい冒険者の開始時

◉  ·  ·  ■  ??                ◉  ·  ·  ■  新
■  ■  ·  ■  ??       →        ■  ■  ·  ■  新
·  ·  ·  +  ??                ·  ·  ·  +  新
■  ?? ?? ?? ??                ■  新 新 新 新
```

- `◉`、`·`、`■`、`+`：発見済みのため位置と地形を固定
- `??`：未探索のため、新しい冒険者の開始時に生成可能
- `新`：内部では生成済みだが、プレイヤーには `??` と表示
- 発見済み領域と新規領域の境界には、到達可能な扉または通路を最低1つ作る
- 生成後に、開始地点からボス部屋まで到達できることを自動検査する

## 第1版での段階導入

1. 5×5程度の固定地図を表示する
2. 現在地と上下左右の移動を実装する
3. 3～5歩ごとのランダムエンカウントを実装する
4. 1階につき通常敵3体という上限を実装する
5. 視認済み・訪問済み・未探索を区別する
6. 発見済み地図をJSONへ保存する
7. 新しい冒険者が同じ地図を受け継ぐ
8. 未探索領域だけのランダム生成を追加する

ランダム生成は、固定地図、ランダムエンカウント、地図継承が正しく動いた後に実装する。
